### Встановлення

1. Клонуйте репозиторій:
```bash
git clone https://github.com/rollerory/template-white.git
```

2. Перейдіть до директорії проекту:
```bash
cd template-white
```

3. Встановіть залежності:
```bash
npm install
# або
yarn install
```

### Доступні Скрипти

- `npm run dev` - Запуск сервера розробки
- `npm run build:dev` - Збірка

## Сторінки

В App.jsx підключаютьтся лише сторінки з `src/pages/`, всі ж блоки підключаються вже в цих сторінках (header і footer не потрібно, тільки те що в мейні). 

### Структура Стилів

Основний конфігураційний файл стилів знаходиться в `src/styles/vars.scss`.
Сюди вписуються основні стандартні значення для контейнера, заголовків і параграфів, кольори, міксіни і тд.

### Основний Файл Стилів

Всі базові стилі автоматично встановлюються в `src/styles/style.scss`. Файл використовує змінні з `vars.scss`. Основні глобальні зміни (не компоненти) бажано робити тут.

### Зберігання та Доступ до Зображень

Всі зображення проекту (крім favicon) зберігаються в `src/assets/images`. Для використання зображень в компонентах, ви можете посилатися на них через аліас `@img/`. Наприклад:

import image from '@img/example.jpg';

Цей аліас автоматично налаштований в проекті та забезпечує зручний спосіб доступу до зображень з будь-якого компонента.

якщо з якогось документу треба доступ в src, то `@/`.

### Шляхи в Посиланнях

В проекті посилання слідують таким конвенціям:
- `/` - посилання на головну сторінку
- `/page-name` - посилання на інші сторінки
- `/page-name#element` - посилання на конкретні блоки на сторінках

Наприклад:
```jsx
<Link to="/">Головна</Link>
<Link to="/about">Про нас</Link>
<Link to="/#head">Top</Link>
<Link to="/about#pricing">Ціни</Link>
```

### Логіка Модального Вікна та Форм

Проект включає систему модальних вікон з наступними функціями:
- Логіка відкриття/закриття модального вікна реалізована в контексті
- Форми автоматично використовують цю логіку модального вікна при заповненні required полів
- Модальне вікно показує повідомлення про валідацію для обов'язкових полів, які не заповнені

Наприклад, коли форма містить обов'язкові поля:

```jsx
<form>
  <input type="text" required />
  <input type="email" required />
  <button type="submit">Відправити</button>
</form>
```

Модальне вікно автоматично обробляє валідацію та відображає відповідні повідомлення.

### Конвенції Назв

- Для текстових елементів, які мають спільні стилі, перший клас повинен бути `text`
- Для заголовків, які мають спільні стилі, перший клас повинен бути `title`
